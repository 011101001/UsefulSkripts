# Gameplay

Small improvements to everyday gameplay mechanics.

| Script | Feature | Usage |
| --- | --- | --- |
| [SleepVoting.sk](./SleepVoting.sk) | Skip the night after a configurable share of players sleep | Automatic |
| [CustomCrafting.sk](./CustomCrafting.sk) | Register an editable sample shaped crafting recipe | Load once; requires SkBee |

SleepVoting checks players in the same world as the sleeper. CustomCrafting requires SkBee 3.0+ and includes a sample name tag recipe. Customize the recipe ID before adding more recipe definitions.
