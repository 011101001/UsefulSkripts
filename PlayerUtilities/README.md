# Player Utilities

Small player-facing quality-of-life features.

| Script | Feature | Command |
| --- | --- | --- |
| [DurabilityAlerts.sk](./DurabilityAlerts.sk) | Low-durability equipment warnings | Automatic |
| [DeathLocation.sk](./DeathLocation.sk) | Save and display the last death coordinates | `/deathloc` |
| [AFKSystem.sk](./AFKSystem.sk) | Manual and automatic away status | `/afk` |

AFKSystem marks inactivity and announces status changes. It does not kick or punish players.
